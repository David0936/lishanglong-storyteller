# 人物转折深挖工作流

人物小传常把十年压成一句话：“经历X，从此形成Y。”这句话只能定位选题，不能直接当故事。真正的故事发生在旧秩序失效、人物必须选择的那一刻。

## 一、先做转折审计

从文件中提取所有“从A到B”的变化，不急着写。逐项建立：

| 字段 | 要回答的问题 |
|---|---|
| 转折前 | 他原来相信什么、依赖什么、每天怎么过？ |
| 压力 | 哪个问题已经积累了一段时间？ |
| 触发 | 哪个具体事件让旧办法突然失效？ |
| 选择 | 当时有哪些选项？他主动放弃了哪个？ |
| 行动 | 决定后的24小时或7天内，他具体做了什么？ |
| 代价 | 他失去了什么、得罪了谁、承担了什么风险？ |
| 反馈 | 外界给了什么可观察的回应？ |
| 变化 | 后来哪些连续行动证明他真的变了？ |
| 解释 | “从此我明白……”是当时想法，还是多年后的总结？ |

把材料原文能证明的内容标为“已知”，合理但未证实的联系标为“待证”，完全没有材料的部分标为“缺口”。禁止把“待证”写成事实。记录已知事实时使用“主语—动作—来源”的原子句，尤其不能把甲的态度、乙的动作和人物后来的解释压成一句话。

同时标记叙述时间：用户今天说“我当时觉得……”只能证明这是他今天对当时的回忆；除非有同期记录或他明确确认，不要改写成“他当晚说过……”或把现在的措辞放进当年的引号。

## 二、判断它是不是转折

真正的转折至少改变一项：目标、身份、关系、资源配置或持续行为。仅有情绪、顿悟金句、一次爆款或多年后的总结，不自动构成转折。

用四项各1-5分排序：

1. 证据强度：是否有本人原话、同期记录或多源交叉证明？
2. 情绪张力：人物是否失去过东西、害怕过什么？
3. 因果清晰度：能否说明为什么是这件事推动了后续行动？
4. 受众相关性：观众能否从这个选择里看见自己的处境？

优先深挖总分最高的一处。证据强度低于3分时，先调查，不写结论。

## 三、一次只问一刀

第一刀优先问动作，不问抽象感受：

- “那件事结束后，你走出门做的第一件事是什么？”
- “你做决定前，最后一个劝你别这么做的人是谁？他说了哪句话？”
- “如果当时不选这条路，你准备走哪条路？”
- “这个决定最先让你失去了什么？”
- “哪一个后续动作能证明这不是三分钟热度？”

回答出现概括词时继续追：

- “很孤独” → 当天几点、在哪、手机里最后联系的是谁？
- “被迫转型” → 谁或什么把原来的路堵死了？
- “突然醒悟” → 醒悟前后各做了什么不同的动作？
- “从此坚持” → 第一次差点放弃发生在哪一天？

不要问“这件事对你有什么影响”。它会得到已经包装好的答案。先还原现场，再让意义从行动中长出来。

### 多轮深挖账本

不要每轮重做整张表。内部持续维护一份账本：

| 状态 | 内容 |
|---|---|
| 已确认 | 用户或可靠来源新确认的原子事实 |
| 已关闭缺口 | 哪个因果问题已经有答案 |
| 待证 | 合理但仍缺证据的联系 |
| 新缺口 | 这次回答暴露出的关键缺口 |
| 下一刀 | 当前最靠近主因果链的一个问题 |

每轮回复只做三件事：用一句话复述新确认的动作；必要时指出它改变了原先哪个判断；只问下一刀。每3-5问或达到门槛时，再给一次简短检查点。

追问顺序默认是“现场→欲望→阻力→选择与替代项→代价→后续行动→事后解释”。用户抛出精彩旁支时先记入账本；除非它会推翻主因果链，否则不要立刻追过去。

停止条件：

- 六项最小可写要素齐全：输出“故事矿石卡”，列明已证事实、主因果链、仍待证内容和适合的成稿版本，然后进入结构卡。
- 连续三刀都得不到动作、证据或新信息：标记“暂不可证”，换下一个高分转折，不用换一种措辞反复逼问。
- 新证据推翻资料里的“觉醒”解释：保留修正。真正的故事可能不是“他因此改变”，而是“他后来如何把一次经历解释成改变”。

## 四、文件案例：摘要不是故事

摘要：“16岁时手机被偷，求助无果，从此明白没人会来救你。”

已知：手机被偷；监控拍到；健身房不当回事；警察只做记录；人物联系对方并提出赎回；“没人会来救你”来自后来的公开讲述。

不能直接断言：他在雪地里当场完成了世界观转变，也不能补写当时的表情、步伐或内心独白。

优先追问：

> 警察拒绝继续处理以后，你离开那里做的第一件事是什么？

根据回答再追：为什么愿意付那笔钱、钱从哪里来、有没有赴约、当晚告诉了谁、第二天采取了什么行动，以及“没人会来救你”这句话第一次出现是什么时候。这样才能判断它是即时触发、逐渐形成的认识，还是多年后的叙事框架。

## 五、调查与成稿门槛

不能采访本人时，按顺序找：本人同期内容、本人后来的完整复盘、在场者说法、同期数据或记录、可靠媒体。搜索目标是补“行动与因果”，不是再找一篇相同的简介。

满足以下六项才进入结构卡：

- 一个可核实的具体场景
- 一个当时的具体欲望
- 一个阻力或冲突
- 一次有替代选项的选择
- 一个真实代价
- 一个后续行动证明变化发生

若缺项，交付“已知事实 + 因果缺口 + 下一步采访/检索问题”，明确说明暂不成稿。

## 六、从一条故事到人物长口播

完成一条转折后，不要立刻把人物所有节点串成流水账。先写出一句主因果链：“因为哪种长期处境，他在什么触发下做了什么选择，付出什么代价，之后用哪些连续行动把自己变成了谁。”

约5分钟的人物口播只保留一条主因果链。可以增加最多两个已达到成稿门槛的转折，用来证明这不是偶然；其余节点只作为时间标记，不展开。逻辑解释必须回答“为什么这个选择在当时成立”和“后来什么行为证明变化真实发生”，不能用一句金句替代因果。
