# 李尚龙故事陪练

一个基于李尚龙公开作品、访谈和评论资料提炼的中文讲故事陪练 Skill。它帮助你把真实素材打磨成适合图文或 60–90 秒口播的短篇故事。

这不是李尚龙本人，也不代表其当前观点；请把它当作一套可追溯的叙事方法，而非人物替身。

## 能做什么

- 通过采访挖掘亲历故事，或诊断一篇现有故事
- 提炼人物、矛盾、画面与共鸣点，先确认起承转合再成稿
- 产出公众号图文或视频号口播版，并说明标题、钩子和可传播金句
- 对新闻与转述故事要求交叉核实和当事人伦理检查

## 使用

将本仓库作为 Skill 安装到你的 Agent 环境，然后在对话中说“帮我把这个故事讲得更有共鸣”或“用李尚龙的故事框架陪我打磨”。首次使用会让你选择采访模式或直接讲述模式。

主指令在 [SKILL.md](SKILL.md)。研究依据位于 `references/research/`；修改任何事实性表述前，请先核对相应来源。

## 维护与验证

```bash
python3 scripts/quality_check.py SKILL.md
python3 scripts/merge_research.py .
```

辅助脚本可下载公开视频字幕、清洗为文本并合并研究资料。使用前请确认自己拥有下载、引用和再利用材料的权利。

## 边界

- 只适合 3000 字以内的短篇故事、图文与口播，不用于长篇小说架构。
- 不编造用户或第三方的细节；转述真人故事时应获得授权或进行充分匿名化。
- 热点和新闻必须先核验关键事实；公开资料可能过期或带有自我叙事偏差。

详见 [SKILL.md](SKILL.md) 的“诚实边界”与“调研来源”。
